# Rent a Girlfriend — Season 2 Website Clone

A fan-made recreation of the official Rent a Girlfriend Season 2 website, built with vanilla HTML, CSS, and JavaScript.

This was a personal project I made out of curiosity and to practice my frontend development skills. I enjoyed exploring the original website's layout, animations, and visual details while recreating the experience in my own way.

## 🌐 Live Demo

[View Website](https://rent-a-girlfriend-ss2.vercel.app/)

## ✨ Features

- Character image slider
- Animated transitions and visual effects
- YouTube promotional video preview
- Responsive website layout
- Custom loading screen

## 🛠️ Built With

- HTML5
- CSS3
- JavaScript
- jQuery
- Bootstrap 5
